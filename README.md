# HR Analytics Dashboard - PowerBI

## Project Overview
This Power BI dashboard provides comprehensive insights into workforce demographics, compensation, employee distribution, and leave management. The dashboard enables HR teams and management to monitor workforce trends and support strategic decision-making.

## Dataset Features
- Employee ID
- Employee Name
- Gender
- Education Qualification
- Date of Joining
- Job Title
- Salary
- Age
- Leave Balance

## Key Performance Indicators (KPIs)
- Total Headcount
- Average Salary
- Average Leave Balance
- Total Male Employees
- Total Female Employees

- ## Dashboard Insights

### Workforce Analysis
- Headcount by Gender
- Headcount by Job Title
- Headcount by Age Groups (Bins)
- Headcount Trend by Year of Joining

### Compensation Analysis
- Average Salary by Education Qualification
- Minimum Salary by Job Title
- Top Earner in Each Job Title
- Salary Distribution Across Workforce

### Leave Management Analysis
- Average Leave Balance by Job Title
- Employee Leave Trends

### Employee Segmentation
- Employee Filter by Starting Letter
- Job Title-wise Employee Distribution
- Gender-wise Workforce Distribution

- ## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling

## Business Value
- Understand workforce composition and diversity.
- Analyze compensation structures across roles.
- Monitor employee leave balances.
- Identify high-performing and top-earning employees.
- Support HR planning and workforce management decisions.
